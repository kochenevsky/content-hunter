## URL-структура

### Основные страницы

| URL | Страница | Приоритет SEO |
|-----|----------|---------------|
| `/` | Главная | Высокий |
| `/services` | Контент-завод (услуги) | Высокий |
| `/cases` | Кейсы (список) | Высокий |
| `/cases/[slug]` | Детальная страница кейса | Средний |
| `/pricing` | Тарифы | Высокий |
| `/blog` | Блог (список) | Средний |
| `/blog/[slug]` | Статья блога | Средний |
| `/about` | О компании | Средний |
| `/faq` | Частые вопросы | Средний |
| `/contact` | Консультация / Заявка | Высокий |

### Служебные страницы

| URL | Страница |
|-----|----------|
| `/admin` | Админ-панель Payload |
| `/api/leads` | API заявок |
| `/sitemap.xml` | XML карта сайта |
| `/robots.txt` | Robots |
